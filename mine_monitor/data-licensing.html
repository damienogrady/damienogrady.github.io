Data licensing and MERIT Hydro

Contains information derived from MERIT Hydro, available under the Open Database License (ODbL) 1.0. The project owner has selected the ODbL option offered by the source for this demonstration. Cite Yamazaki et al. (2019); MERIT Hydro copyright belongs to its developers.

The analysis transformed the HAND band into H1–H10 categorical strata on the analysis grid. These strata informed control matching; neither raster is included in the website package. Machine-readable outputs that explicitly carry these labels include:

The public MERIT Hydro-derived data folder provides the full HAND-label raster and matching table, with a README and checksums. These companion files are hosted separately from the website.

  • Landsat control-summary Parquet and Sentinel-2 control-summary Parquet.
  • Caliper-exclusion CSV and Control-reuse CSV.
  • Dashboard JSON and the fitted-NDVI viewer's matched-pair tile records.

The project owner has accepted these sharing arrangements for this demonstration. These files retain their existing provenance and their applicable third-party terms. Future operational or client-backed use requires its own licensing and attribution assessment.
